This thesis trains a CNN to detect the tube ends of stacked construction fence panels using only synthetic images composed from six cut-out tube ends and seven backgrounds. On an unseen real test image it reaches an mAP@0.5 of *0.955*. Blending the pasted objects into their surroundings is decisive: without it, the detector loses about 14 percentage points, which synthetic validation data does not reveal. Object size at the network input matters most.
