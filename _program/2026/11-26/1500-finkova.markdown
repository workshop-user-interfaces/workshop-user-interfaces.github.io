Reprobooktor is a screenless audiobook player designed to solve accessibility issues faced by visually impaired older adults. Users select their desired title using a physical dial and then open the device like a book to start playing. To keep the device easy to use for the listener, it is accompanied by a web dashboard where caregivers can remotely manage audio files.
