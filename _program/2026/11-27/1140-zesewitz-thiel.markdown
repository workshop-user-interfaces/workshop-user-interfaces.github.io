This talk addresses the question of how an augmented reality (AR) application can be developed for care staff to provide an intuitive visualization of data collected by sensors installed in a resident’s living space—data that is otherwise inaccessible—during rounds, routine care, or general support. The objective is to create an AR application that offers low-threshold access to this data, utilizing the Meta Quest 3 headset and the Mixed Reality Utility Kit within the Unity development environment, thereby assisting caregivers in their daily tasks. The central research question guiding this project is: What design principles and functional requirements must an AR user interface meet to provide care staff with user-friendly, low-threshold access to sensor data within a ""Smart Co-Care"" apartment? Finally, potential users participated in an ex-post evaluation, which included a user interview and a hands-on testing phase of the application. The results indicate that care staff hold a positive view of the application. A key positive aspect noted was the project’s ability to provide insight into information that is otherwise invisible—for example, observing a resident’s behavior during the night. The evaluation results highlighted certain issues and critical aspects of the application that are essential for ensuring low-threshold, accessible usage. Consequently, data more relevant to nursing practice needs to be prepared. Compatibility with existing software must also be ensured so that the application can be effectively integrated into the workflow. Ultimately, the scientific added value lies in the presentation of a solution for a practical application that enables nursing staff to review information—which would otherwise be inaccessible—over an extended period.
